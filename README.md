# 招聘综合工作台原型

本地、无依赖的 HTML 原型。按钮 1 通过 iframe 加载 WorkBuddy 分享页；按钮 2、3 为占位页。

## GitHub Pages

本项目以静态网页形式发布，直接使用仓库根目录的 index.html，无需依赖安装或构建。服务器脚本仅用于本地预览。

## 预览

在此目录执行 `node server.cjs`，然后打开 http://127.0.0.1:4173 。使用完毕按 Ctrl+C 关闭服务。也可以直接用浏览器打开 index.html，但建议用本地 HTTP 地址进行嵌入测试。

## 验证

确认 iframe 中是否实际显示招聘数据，并手动检查日期筛选等交互。页面加载事件不能证明嵌入成功，父页面无法读取跨域 iframe 内部状态。若无法显示，请使用“在新窗口打开”区分原站问题和嵌入限制。

此原型只验证页面集成，不复制或同步 WorkBuddy 数据。正式部署的域名、浏览器登录状态及原站后续策略变化均可能影响嵌入结果。

## 本次测试结果（2026-10-27）

- 本地 HTTP 页面返回 200，三个导航按钮均可正常切换，按钮 2、3 显示占位内容。
- 分享链接单独打开时正常显示招聘漏斗、日期筛选及日报。
- 将分享链接嵌入本地页面时，分享外壳可以加载，但内部看板显示“拒绝了我们的连接请求”。
- 内部页面响应头包含 Content-Security-Policy 的 frame-ancestors 指令，只允许指定的 WorkBuddy / 腾讯等域名作为祖先页面，未包含本地工作台域名。此限制检查整个 iframe 祖先链，因此通过分享外壳再次嵌套仍会被拦截。

结论：当前链接不能直接用于这个独立工作台的 iframe 嵌入。可以使用新窗口入口，或从 WorkBuddy 导出网页源码并独立部署；也可向平台确认是否支持为自有域名开放嵌入。
